【服饰智能客服演示知识库 - 售后与退换指南】

重要说明：本文件为 RAG 项目演示资料，不是特定平台的官方售后承诺。实际退换条件、时限、运费和例外商品，应以订单页、商品详情页、平台规则及商家客服最终确认为准。

一、收到包裹后的检查顺序
1. 先检查外包装是否破损、受潮或被拆封。
2. 核对订单商品、颜色、规格、尺码和数量是否一致。
3. 检查吊牌、洗标、配件、赠品和包装是否齐全。
4. 在干净环境中试穿，避免化妆品、香水、汗渍或污渍沾染商品。
5. 发现问题时及时拍摄清晰照片或视频，保留外包装和快递面单。

二、无理由退换的一般注意点
- 是否支持、申请时限和运费承担以商品页与平台规则为准。
- 商品通常应保持完好、未洗涤、未穿着外出，吊牌和配件齐全。
- 定制、贴身类、已拆封的个人使用类商品可能存在特殊限制。
- 不要先自行剪除吊牌、清洗或修改商品后再申请，否则可能影响判定。
- 退回前按客服要求包装，保留寄回物流单号与发货凭证。

三、尺码不合适
1. 先确认目标尺码是否有库存，并核对商品尺码表。
2. 询问用户身高、体重、胸腰臀围和偏好松量，帮助选择换货尺码。
3. 换货时说明是否支持同款换码、换色或退货重拍，以订单页实际选项为准。
4. 若商品存在偏码反馈，应记录批次和版型信息，便于后续知识更新。

四、质量问题处理
常见问题包括破洞、开线、明显污渍、严重色差、拉链损坏、配件缺失、洗后异常缩水或不符合标注成分。
处理步骤：
1. 拍摄整体图、问题局部特写和吊牌/洗标照片。
2. 说明首次发现时间、是否洗涤、洗涤方式和是否使用过其他产品。
3. 保留商品原状，未与商家确认前避免继续清洗或自行修补。
4. 由客服根据平台规则判断退换、维修、补发配件或补偿方案。
5. 不得在未核验时直接承诺“必定退款”或“必定属于质量问题”。

五、色差与屏幕显示
1. 不同屏幕、拍摄光线和后期处理会造成颜色差异。
2. 用户认为色差明显时，可请其在自然光下拍摄实物，并同时提供商品页图片。
3. 轻微色差通常在正常范围内；是否属于明显不符需结合平台和商家规则判断。
4. 黑色、深蓝、酒红和高饱和颜色在不同光线下更容易出现视觉差异。

六、掉色、缩水与起球
1. 先确认洗涤方式是否符合洗护标签，是否浸泡过久、使用高温或混洗。
2. 天然纤维轻微缩水、深色棉织物首次浮色和羊毛起球可能与材质特性有关。
3. 若超出商品说明或明显影响穿着，应收集洗涤条件、照片和标签信息，交由售后判断。
4. 客服不得仅凭一张照片直接确定责任，复杂情况应升级人工质检。

七、物流与包裹异常
1. 物流长时间未更新：先核对收件地址、联系电话和物流节点，再联系承运方核查。
2. 包裹破损：建议当场拒收或拍照留证，并立即联系平台或商家。
3. 显示签收但未收到：确认家人、前台和快递柜，并及时提交物流查询。
4. 错发/漏发：提供订单号、开箱照片、面单和收到商品清单。
5. 未经核实不要向用户承诺具体赔偿金额。

八、退款与换货进度
- 退款到账时间取决于支付渠道和平台处理状态，应引导用户查看订单售后详情。
- 换货进度应结合仓库收货、质检和发货状态回答。
- 若超过页面承诺时限，可建议用户提供售后单号并由人工客服跟进。

九、客服沟通要点
1. 先表达理解，再确认“订单号、商品、问题、已采取的处理步骤”。
2. 只回答有依据的政策；不确定时说明需要进一步核实。
3. 涉及人身安全、皮肤不适或严重质量问题，优先建议停止使用并升级人工处理。
4. 不索取与售后无关的敏感信息，不要求用户提供完整身份证号、银行卡号或密码。
5. 每次政策更新后应及时更新知识文档并注明生效时间。
