【服饰智能客服演示知识库 - 场景穿搭建议】

适用范围：本资料提供通用风格与搭配思路，不替代企业着装规范或活动主办方 dress code。

一、职场通勤
1. 核心原则：利落、整洁、便于活动，颜色控制在两到三种。
2. 常用组合：衬衫 + 直筒裤、针织衫 + 半身裙、西装外套 + 牛仔裤、连衣裙 + 轻量外套。
3. 颜色：黑、藏青、灰、米白、卡其和低饱和蓝绿更容易组合。
4. 面料：有垂感或适度挺括的面料更显精神；贴身层优先关注透气。
5. 细节：裤长不堆积、衬衫领口平整、鞋包风格统一，可提升整体完成度。

二、商务正式
1. 先确认 dress code 是否要求商务正装、商务休闲或鸡尾酒礼服。
2. 西装重点检查肩线、胸扣闭合和袖长；裤装关注裤腰和裤长，裙装关注坐姿与裙长。
3. 颜色以深蓝、深灰、黑色和中性色为主，配饰控制在简洁范围。
4. 皮鞋、腰带和包袋尽量保持材质与颜色协调。
5. 若需长时间站立，应优先测试鞋底舒适度和服装活动量。

三、休闲约会
1. 可选择柔和色、莫兰迪色或一件具有设计感的主单品。
2. 针织开衫 + 半身裙、短外套 + 高腰牛仔裤、简洁连衣裙都易于控制完整度。
3. 约会场景优先考虑坐下、行走和用餐时的舒适度，避免过度紧绷或易走光单品。
4. 配饰不必过多，选择耳饰、包袋或鞋履中的一个视觉重点即可。

四、旅行与城市漫步
1. 选择可重复搭配的上衣和下装，减少行李数量。
2. 优先快干、抗皱、轻量和有口袋的单品；鞋履需兼顾长时间步行与场景适配。
3. 温差场景可采用“打底 + 中层 + 轻外套”的分层结构。
4. 深浅色组合时，至少保留一件耐脏下装，并准备应对天气变化的轻薄外层。
5. 机场安检和长时间乘坐时，避免过多金属装饰与过紧腰头。

五、运动与户外
1. 跑步、健身：关注排汗、快干、弹力和接缝摩擦，鞋履需匹配运动类型。
2. 徒步：关注分层穿衣、防风防雨、透气和活动空间，不建议用普通棉质内层长时间徒步。
3. 骑行：注意裤装摩擦、反光细节、防风性和收纳口袋。
4. 露营：晚间增加保暖层，外层预留内搭空间；颜色可选择更易识别的亮色。
5. 户外功能服不应只看宣传参数，还应结合气温、湿度、强度和持续时间选择。

六、聚会与节日
1. 可把亮色、金属光泽、蕾丝或特殊廓形集中在单一主单品上，其余保持简洁。
2. 深色背景聚会可使用低饱和亮色或局部反光材质；白天聚会更适合轻盈面料与清透配色。
3. 若活动包含长时间站立，优先选择稳定鞋跟和透气内里。
4. 需要拍照时，可关注领口、腰线和材质层次，避免全身大面积复杂图案。

七、四季叠穿
1. 春季：T恤/薄针织 + 衬衫或风衣，内薄外厚便于温差调整。
2. 夏季：轻薄天然纤维或功能速干面料，浅色降低吸热，注意透光与防晒。
3. 秋季：针织 + 西装/风衣 + 直筒裤，利用薄厚与长短形成层次。
4. 冬季：贴身保暖层 + 针织/抓绒中层 + 防风外套；避免每层都过紧影响血液循环和活动。

八、胶囊衣橱思路
建议选择 2 个主色、1 个点缀色，并确认上下装、内外层可以互相组合。可优先配置：
- 合身白衬衫或针织上衣
- 基础 T 恤
- 直筒或阔腿长裤
- 一条中长半身裙
- 西装外套或风衣
- 轻量针织开衫
- 深色牛仔裤
- 一双通勤鞋和一双休闲鞋

九、客服回答原则
1. 先询问用户要去的场景、时间、气温、活动强度和个人风格偏好。
2. 推荐时说明“主单品 + 配色 + 外层 + 鞋包”的完整组合，而不是只推荐一件衣服。
3. 若用户需要购买建议，提醒结合库存与商品详情页中的版型和面料。
